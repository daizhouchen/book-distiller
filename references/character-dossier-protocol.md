# 人物小传协议（Character Dossier Protocol · §2.7）

**v2.1 新增**——本协议规范 `character_dossiers` 字段（per `deepening-protocol.md` §2.7 / §4.5）的填写。它把"对人物写厚"从单点剖面落到跨章节聚合的完整档案。

> 人物小传不是"人物简介百科条目"。它是把一个人物在全书各章的零散事实**聚合成一份完整档案**——出场轨迹、核心矛盾、关键场景、语言印记、命运模式，最后用本书母题视角做一次再读。

---

## §A · 8 子字段 schema 详解（per §2.7）

```json
{
  "name": "人物名（含别名/字号）",
  "tier": "primary | secondary | minor_but_pivotal",
  "appearance_arc": "在书中的出场轨迹 ≥150 字",
  "core_paradox": "人物的核心矛盾 一句话 ≤30 字",
  "key_scenes": [
    {"scene": "关键场景定位", "what_it_reveals": "暴露了人物的什么 ≥60 字"}
  ],
  "language_signature": "人物的语言印记（说话方式、用词偏好）≥80 字",
  "fate_pattern": "命运模式 ≥150 字",
  "reading_through_lens": "从我们的母题视角看这个人物 ≥150 字"
}
```

每条总字数 ≥**600**。

### A.1 · `name`

人物的常见称谓 + 别名/字号/绰号。例：
- "林黛玉（颦颦、潇湘妃子）"
- "宋江（公明、及时雨、孝义黑三郎）"
- "李逵（黑旋风、铁牛）"

别名往往承担信息——绰号是江湖看法，字号是文人自况，闺名是亲密关系——必须并列写出。

### A.2 · `tier`（人物层级）

三档：
- **primary**：全书核心、母题主要承载者（红楼之黛玉宝玉、金瓶之西门庆潘金莲）
- **secondary**：重要配角、情节关键节点（红楼之凤姐、金瓶之应伯爵、水浒之吴用）
- **minor_but_pivotal**：戏份不多但承担关键功能（红楼之秦可卿、贾环、赵姨娘；金瓶之韩道国；水浒之李师师）

> **tier 选择的判定信号**：
> - primary：删了这个人物，全书坍塌
> - secondary：删了这个人物，整章失衡
> - minor_but_pivotal：戏份少但删了之后**某个关键转折无法发生**——这是 v2.1 特别强调的层级，因为传统人物简介往往只写主角，把"戏份少但作用关键"的人忽略

每份 dossier 集合应包含全部三档（不能只写 primary）。

### A.3 · `appearance_arc`（出场轨迹，≥150 字）

按时间顺序记录人物在书中的所有重要出场点（不是每场都列，是关键节点）：
- 第一次出场（在哪一回 / 一章 / 哪个场景），第一次出场承担什么定调
- 中段的关键节点（地位/状态变化）
- 最后一次出场（结局）

**写法重点**：不是事件流水账，是"人物状态的演化曲线"——从 A 状态到 B 状态到 C 状态，每个状态由一个标志性场景锚定。

### A.4 · `core_paradox`（核心矛盾，≤30 字）

⭐ 最浓缩的功夫。一句话写出人物身上**两个相反力量的角力**。

判定标准：
- 必须是矛盾（不是性格描述）
- 必须 ≤30 字（写得长 = 没浓缩到位）
- 必须能解释人物大部分关键行为（不是只解释一两件事）

举例（红楼）：
- 林黛玉：**清醒地知道孤独无救，仍要为之书写**（21 字）
- 王熙凤：**用最强的能力维持一个必败的家**（17 字）
- 贾宝玉：**生在权力顶端，志在权力之外**（15 字）
- 薛宝钗：**她的克己不是修养，是恐惧**（13 字）
- 秦可卿：**她活着是隐喻，死了才显形**（13 字）

写不出 ≤30 字的 core_paradox，说明对这个人物理解还不够——回去重新读他的所有关键场景。

### A.5 · `key_scenes`（关键场景，≥3 条）

```json
[
  {"scene": "场景定位（章节+一句话）", "what_it_reveals": "暴露了人物什么 ≥60 字"}
]
```

选择标准（与 §2.6 场景细读不冲突，但侧重不同）：
- §2.6 选"全书母题枢纽场景"
- §2.7 选"人物自身的关键时刻"

二者可重合（如葬花既是全书母题枢纽，也是黛玉关键场景），但 §2.7 的 key_scenes 要从**人物视角**写——这一场让我们看清这个人的什么？

### A.6 · `language_signature`（语言印记，≥80 字）

⭐ 这是人物小传的"指纹"层。每个人物说话都有自己的频率、用词、句式偏好。

要素：
- **频率**：话多 vs 话少（黛玉话不多但每次都狠；凤姐话太多必有目的）
- **用词偏好**：雅 / 俗 / 文 / 白 / 软 / 硬
- **句式**：长句 vs 短句、设问 vs 陈述、命令 vs 商量
- **口头禅 / 标志性短语**（如凤姐"什么阿物儿" / "罢罢罢"；黛玉"你死了，我做和尚去"）
- **沉默时刻**——什么时候这个人不说话？（沉默本身是签名的一部分）

### A.7 · `fate_pattern`（命运模式，≥150 字）

人物的命运不是一系列事件，是一个**模式**——他会一再走入同一种情境，一再做出同一种选择，一再被同一种力量打回。

写法：
- 这个人物的命运可以归纳为一句话模式（如"凤姐：能力越强，反噬越大"；"黛玉：每一次预感都成真"；"宝玉：每一个想守护的人都在他眼前消失"）
- 然后给出 ≥3 个事件作为这个模式的实例
- 最后讨论这个模式和书的母题的关系

`fate_pattern` 字段在史书人物 dossier 里尤其关键——史记列传/三国志的人物有典型的兴衰节奏（如韩信"功高震主→兔死狗烹"、项羽"勇而无略→垓下穷途"），可作为模板。

### A.8 · `reading_through_lens`（母题视角再读，≥150 字）

最后一层——把这个人物放回卷首确立的母题视角，再读一遍。

写法：
- 这个人物如果放在母题里看，他承担的是母题的什么面相？（显化 / 反例 / 枢纽）
- 他和其它人物在母题上是什么关系？（同构 / 对立 / 互补）
- 现代读者从他身上能看到什么？（modern_transfer 的人物版）

> reading_through_lens 是 dossier 区别于"人物词典"的根本。词典是中性的，dossier 是有视角的。

## §B · primary / secondary / minor_but_pivotal 选择逻辑

### B.1 · primary 选择

不超过 5 人（巨著也建议不超过 7 人）。判定信号：
- 出现回数 ≥1/3 全书
- 是全书**至少一条主线**的核心承担者
- 删掉之后全书母题缺一面

### B.2 · secondary 选择

5-15 人。判定信号：
- 多次承担情节推进
- 与 primary 形成关系网（不是孤立）
- 删了会让某条副线坍塌

### B.3 · minor_but_pivotal 选择 ⭐ v2.1 特别强调

3-5 人。判定信号：
- 戏份少（出现 ≤5 次）
- 但**某个关键转折由他触发**或**某个母题面相由他独家承担**
- 没有他这个戏份位置就空了

> **传统读法的盲区**：传统读者只关心主角，但 v2.1 的 character_dossiers 必须把 minor_but_pivotal 写出来——因为这一档人物的存在本身揭示了作者的结构功夫，写得出他们的 dossier 才证明你"读全了"，不是只读了主线。
>
> 红楼的例子：贾环（亲生子却不被疼爱，反衬宝玉的"被宠"是结构性的）；赵姨娘（妾的处境放大了王夫人的位置）；秦可卿（她的死是十二钗悲剧的总预告）；蒋玉菡（宝玉与外部世界的唯一通道）。

## §C · `language_signature` 写法 · 红楼对比例（凤姐 vs 黛玉）

### C.1 · 王熙凤的语言印记（≥80 字示范）

> 凤姐说话**密、快、压、笑里藏刀**。她话量大（每次出场必有大段对白），句式短促有力，常用排比 / 反问 / 戏谑—— "你既吃了我们家的茶，怎么还不给我们家做媳妇？"（25 回）—— 一句话里藏着戏弄、试探、挑明三层。她的语言是一种**社交武器**：表面亲热（"亲家奶奶"、"我的儿"），内里掂量（每一句话都在算）。她也用"我"字最多，是全书最自我中心的发言者。她的沉默时刻最少——一旦凤姐沉默，必有大事（如听贾母骂赵姨娘那一场）。她的语言印记可总结为：**用最热闹的话语制造最冷的距离**。

### C.2 · 林黛玉的语言印记（≥80 字示范）

> 黛玉说话**少、尖、藏、不肯说破**。她话量小（很多场只一两句），但每一句都狠或重。句式偏短、多用反问与设问 —— "我作践坏了身子，我死，与你何干？"（32 回）—— 表面是怒，深处是怕。她爱用"自然"、"原是"、"也罢"等带着自我和解又自我嘲讽的词。她的沉默时刻最多——她的不说本身是一种说，是怕说出来后果太重。她说话总是**带着引号外的引号**——表层是甲，潜文本是乙，再深一层还有丙。她的语言印记可总结为：**用最少的字，写最长的回声**。

> 两人对照看：凤姐是"语言用来制造距离"，黛玉是"语言用来收拢回声"。这种对照写法是 dossier 的灵魂——单写一个人是平面的，对照写两个人就立起来了。

## §D · `core_paradox` ≤30 字范例（5 个红楼人物）

| 人物 | core_paradox（≤30 字） |
|------|------|
| 林黛玉 | 清醒地知道孤独无救，仍要为之书写（17 字） |
| 王熙凤 | 用最强的能力维持一个必败的家（14 字） |
| 贾宝玉 | 生在权力顶端，志在权力之外（13 字） |
| 薛宝钗 | 她的克己不是修养，是恐惧（12 字） |
| 秦可卿 | 她活着是隐喻，死了才显形（12 字） |

> 写 core_paradox 的诀窍：
> 1. 先列出人物身上看似矛盾的两个特征
> 2. 找到那个让矛盾**统一在一种深层逻辑**里的点
> 3. 用最简短的句式写出来
>
> "林黛玉是孤独的"——这是性格描述，不是 paradox。
> "林黛玉清醒地知道孤独无救，仍要为之书写"——这是 paradox，因为"知道无救"和"仍要书写"是张力。

## §H · 思想家小传降级版（论证书 DOWNGRADE，per §4.5）

论证书可以写"承载思想的关键人物" ≥3 位——书中正面引用的代表思想家 + 主要批判靶子 + 作者本人。

8 子字段调整：
- `appearance_arc` → "在书中的引用轨迹"（书中第几次提到、每次的承担）≥150 字
- `key_scenes` → "代表性引用段落" ≥3
- `language_signature` → "思想家的论证印记"（他独特的论证方法、术语偏好）≥80 字
- `fate_pattern` → "思想史地位演化"（被推崇/被批判/被遗忘的循环）≥150 字
- `reading_through_lens` 不变

例：《资本论》的 character_dossiers ≥3 位 → 黑格尔（被改造的对象）+ 亚当·斯密（被吸收的对手）+ 马克思本人（论证发起者）。

## §J · 跨章节聚合的具体做法（per SKILL.md 步骤 5 v2.1）

`character_dossiers` 是事实系统化（步骤 5）的产物之一——同一人物的事实点散落在多章里，必须**先聚合后撰写**。

聚合做法：
1. 对每个候选人物，遍历全书事实矩阵（每个 cell 标注涉及的人物）
2. 把涉及该人物的所有 cells 抽出来，按时间排序
3. 在这些 cells 里找出"状态曲线" → 写入 appearance_arc
4. 找出"重复出现的矛盾" → 浓缩为 core_paradox
5. 找出"重复出现的命运逻辑" → 写入 fate_pattern
6. 从所有对白事实中归纳语言特征 → 写入 language_signature
7. 从所有引用关系中找最关键 3 场 → 写入 key_scenes
8. 最后用母题视角再读一遍这堆事实 → 写入 reading_through_lens

> 不做这个聚合 → dossier 会写成"这一回的人物 + 那一回的人物"的拼贴，缺乏整体性。**聚合是 dossier 的脊梁**。

---

> 人物小传不是人物简介。
> 它是把零散事实聚合成完整档案——出场轨迹、核心矛盾、关键场景、语言印记、命运模式。
> 写不出 ≤30 字的 core_paradox，说明你对这个人物理解还不够。
