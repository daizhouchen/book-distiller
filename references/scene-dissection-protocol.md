# 场景细读协议（Scene Dissection Protocol · §2.6）

**v2.1 新增**——本协议规范 `scene_dissections` 字段（per `deepening-protocol.md` §2.6 / §4.4）的填写。它是 v2.1 把"对书内容写厚"从抽象目标落到具体可量化产出的核心抓手。

> 场景细读不是"摘抄一段然后说几句"。它是把一个 300 字以上的关键场景**像导演拉片一样拆开**——人物怎么站、灯光怎么打、谁先说话谁后说话、说出口的话之外暗藏什么、这一场在全书结构里承担什么扣环。

---

## §A · 何为"值得拆的场景"

不是所有场景都值得 dissection。三个判定信号必须**同时**满足：

### A.1 · 母题相关性（motif-relevance）

场景必须和卷首确立的母题有显著关系——它要么是母题的**显化**（如红楼"葬花"显化"美必凋零"），要么是母题的**反例**（如水浒"林冲风雪山神庙"反衬"忍无可忍"），要么是母题的**枢纽**（同时承担显化与反例的张力点）。

判定方法：把母题一句话写下来，问"如果我从全书里删掉这一场，母题会不会缺一块？"——会缺，就该拆。

### A.2 · 结构枢纽（structural hinge）

场景必须在情节结构上承担**前后扣**。它要么是一条情节线的**入口**（开场预告），要么是**翻转**（命运转折），要么是**闭环**（回声呼应）。流水账式的过场不拆。

判定方法：在全书时间轴上画 5-7 个关键节点，本场必须落在节点上或节点周围的承接段。

### A.3 · 感官密度（sensory richness）

场景必须有**可感的具体细节**——视觉（颜色、光、空间）、听觉（声音、对白节奏）、触觉（温度、质感）、嗅觉/味觉（香气、食物）任意三种以上密集出现。纯抽象的对白场（"两人讨论了半小时哲学"）不是 dissection 对象，因为没东西可拆。

判定方法：原文摘录 300 字，圈出感官词，少于 5 个就跳过。

> 三条同时不满足 → 场景不该入选 scene_dissections，写到精读模块的普通段落即可。

## §B · 5 层拆解结构（per §2.6 schema）

每个 scene_dissection 必须按以下 5 层展开。**字数分布建议**：每层 150-300 字，总字数 ≥1000。

### B.1 · blocking（调度层）

**问什么**：人物在空间里如何站位、如何移动、谁主动谁被动？

- 入退场顺序（谁先到、谁后到、谁先离开）
- 空间布局（房间/园林/旷野，谁靠近中心、谁在边缘）
- 视线方向（谁看谁、谁不敢看谁）
- 身体距离（贴近、相隔几步、隔门隔帘）

戏剧导演视角的"舞台调度"是这一层的工具。**舞台调度本身就是权力关系的可视化**——谁站 C 位、谁背靠墙、谁要绕弯进入，都是潜文本的物质载体。

### B.2 · language（语言层）

**问什么**：作者用了什么词、什么句式、对白节奏如何？

- 用词偏好（雅 vs 俗、文 vs 白、密 vs 疏）
- 句式（长句 vs 短句、对偶 vs 散行、设问 vs 陈述）
- 对白节奏（你来我往的速度、停顿、打断）
- 潜台词（说出口的话和真正想说的话之间的缝）
- 叙事语气（旁白者的态度——冷峻、同情、反讽、哀矜）

这一层是文本细读最传统也最硬的功夫。

### B.3 · sensorium（感官层）

**问什么**：场景里有哪些感官细节？为什么是这些不是别的？

- 视觉：光（晨光/暮色/烛火）、色（朱红/缟素/青翠）、空间（开阔/逼仄）
- 听觉：声（风声/笑语/钟磬/啜泣）、寂静（在哪一刻突然没声音了？）
- 嗅觉：花香、饭香、药味、血腥
- 触觉：温度（冷/热）、质地（绫罗/糙布/泥土）
- 味觉：酒、茶、甜咸

感官细节不是装饰——它是**情绪的物质载体**。同一段对话放在烛光摇曳里和放在正午日头下读出来不是同一件事。

### B.4 · subtext（潜文本层）

**问什么**：没说出来的、被遮蔽的、暗示的是什么？

- 谁的视角被压低了？（场景里谁的反应被作者一笔带过？）
- 谁不该在场却在场？（多余人物的存在本身就是潜文本）
- 谁该在场却不在场？（缺席的关键人物）
- 哪些话戛然而止？（"……"省略号承担什么）
- 这场的表层主题（如"喝茶")和真正主题（如"权力试探"）之间的距离

这一层是 dissection 含金量最高的部分。表层人人能看到，潜文本要"读出来"。

### B.5 · structural_function（结构功能层）

**问什么**：这一场在全书的因果链条里承担什么？

- 前承（呼应了前面哪一场？）
- 后启（预告了后面哪一场？）
- 母题承担（它是母题的哪一面）
- 在人物弧光上的位置（人物从这一场之后变成什么样）

> 此层是写"为什么这一场不能少"——它的存在使得后面的某场才有重量。

## §C · key_close_reads（关键短语细读）

除 5 层拆解外，每条 scene_dissection 还要选 **≥3 个原文中的关键短语**做"放大镜级"细读：

```json
"key_close_reads": [
  {"phrase": "原文中的具体短语 / 词组 / 半句", "reading": "为什么这个细节关键 ≥80 字"}
]
```

短语选择标准：
- 体量很小（一个词 / 一个短句 / 一句对白）
- 信息密度极高（牵动整段甚至整书的解释）
- 容易被一般读者忽略（不是"明显的金句"）

---

## §D · echoes（呼应链）

每条 scene_dissection 必须列 **≥3 处与全书其它场景的呼应**：

- 前后场景的细节对照（如葬花 ←→ 寿怡红夜宴月落）
- 同一道具的反复（如金锁的多次出现）
- 同一动作的变奏（如"哭"在不同场合的不同形态）

呼应链是把单场打通成全书系统的关键——没有 echoes 的 dissection 是孤岛。

---

## §E · 不同基因书的场景选择启发

### E.1 · 人物书 / 叙事书（STRICT）

≥5 条，巨著 ≥8。优先选：
- 人物初登场（性格定调）
- 关键关系建立（情感/权力的契机）
- 命运转折（导致后续不可逆变化的那一场）
- 死亡/分别（命运闭合）
- 结构呼应（前后呼应的对偶场）

### E.2 · 史书 / 纪实文学（STRICT）

≥5 条。优先选：
- 关键决策的现场（赤壁之战火攻夜、垓下之围别姬夜）
- 政变/会盟/朝议
- 历史人物的"命运一刻"

### E.3 · 论证书（DOWNGRADE）

≥2 条例证场景。论证书的"场景"不是叙事场景，是作者用来支撑论点的**情境化论证片段**——
- 康德举的咖啡馆例子
- 尼采"市场之蝇"中的市场场景
- 卢梭"独自漫步"的湖边
- 霍布斯"自然状态"的想象场景
- 马克思《资本论》中"商品拜物教"的工厂车间

这些场景的拆解侧重 language / subtext / structural_function 三层，blocking / sensorium 退居次要。

### E.4 · 美学书（DOWNGRADE / STRICT）

- 纯诗集/格言（道德经、沉思录）：DOWNGRADE ≥2 个语言场景——选语言密度最高的一篇/一段（如《道德经》"上善若水"段）
- 兼叙事的美学书（红楼、追忆、源氏）：STRICT ≥5 条

### E.5 · 模型/工具书（OPTIONAL）

可空。但若书中有标志性"实操剧本"或作者亲身案例（如《非暴力沟通》中调解房产纠纷案），可升级为 1-2 条 dissection 处理。

## §F · 工作示例 1（STRICT）：红楼梦 第二十七回 · 黛玉葬花

> 此例展示 5 层拆解 + key_close_reads + echoes 的完整产出。学习者应能照此模板写其它书的 dissection。

**scene_title**：黛玉葬花

**scene_locus**：第二十七回 · "滴翠亭杨妃戏彩蝶 / 埋香冢飞燕泣残红"——午后众人园中游耍后，黛玉独行至沁芳闸畔花冢，见落红满地，乃葬花并诵《葬花吟》。

**original_text_excerpt**（≥300 字）：
> "一面说，一面顺着脚一径走去。刚到了梨香院墙角上，只听见墙内笛韵悠扬，歌声婉转。林黛玉便知是那十二个女孩子演习戏文呢。只是林黛玉素习不大喜看戏文……尔今死去侬收葬，未卜侬身何日丧？侬今葬花人笑痴，他年葬侬知是谁？……一朝春尽红颜老，花落人亡两不知！"

### 五层拆解

**§B.1 · blocking**（调度）：
全场只有黛玉一人独行，宝玉在远处隔花听见啜泣。空间是封闭的小路 → 花冢 → 沁芳闸的递进，越走越深越窄。重点是**视线的不对等**——黛玉以为无人，宝玉躲在花后听见。这种"被听见而不自知"的调度是全书的关键编排：黛玉的真情独白多次被宝玉/作者偷听记录，构成她的命运不能自主的视觉隐喻。她以为在和自己说话，其实每一次自语都在为"被偷听者"准备。

**§B.2 · language**（语言）：
《葬花吟》是七言古诗，五十二句、长短交错，比一般律诗松。**关键句式技巧**：用一连串疑问句（"花谢花飞花满天，红消香断有谁怜？"）和倒装（"侬今葬花人笑痴，他年葬侬知是谁？"），把"我"和"花"反复对调位置——花是我，我是花，花的命运预告我的命运。这种"主客互换"的修辞是古典悼亡诗的传统手法，但在这里被推到极致：连葬花的动作本身都成了对自己的预演。

**§B.3 · sensorium**（感官）：
视觉密度极高——"残红"、"花满天"、"红消香断"、"绣球花"、"杏子阴"、"水溶溶"。颜色集中在红与白（落英 + 帕子）。听觉上，前段有梨香院的笛歌（生）反衬黛玉这边的啜泣（死），构成全场最重要的声音对比。嗅觉是隐藏的——花冢必有腐香，但作者不写，留给读者自己嗅出来。**重点**：感官的"过满"和情绪的"过空"形成张力，读者被花的实感淹没，黛玉被花的虚无淹没。

**§B.4 · subtext**（潜文本）：
表层是少女伤春，潜文本至少三层：
1. **预演自己的死亡**——"未卜侬身何日丧"已经把"葬花"翻译成"葬己"，黛玉在自己的葬礼上扮演自己。
2. **对"被收葬"的怀疑**——"他年葬侬知是谁"暗藏对宝玉的不信任：连花都有人葬（黛玉自己），但她自己呢？这不是少女撒娇，是清醒的孤独认知。
3. **对整个贾府的判词**——"一朝春尽红颜老，花落人亡两不知"不只是写自己，是写所有"花"（女儿们），是写整个园子的将来。

**§B.5 · structural_function**（结构功能）：
- **前承**：第二十三回 "西厢记妙词通戏语 / 牡丹亭艳曲警芳心"——那一回是黛玉第一次因"良辰美景奈何天"流泪，本回把那次预感落到具体的葬花动作上。
- **后启**：第七十六回 "凹晶馆联诗 / 寒塘渡鹤影"——黛玉与湘云联出"寒塘渡鹤影，冷月葬花魂"，"葬花魂"三字直接呼应本回，且把"葬花"升级为"葬魂"。
- **母题承担**：本场是"美必凋零 + 凋零者无人收葬"的核心显化——红楼整本书的悲剧观，在这一场被压缩成 52 句诗 + 一个动作。
- **人物弧光**：黛玉至此正式从"小性儿"少女转入"诗魂"形象——她的命运观从这一场起被锚定，后面所有诗作都是这个观点的延伸。

### key_close_reads（≥3 条）

```
phrase: "尔今死去侬收葬，未卜侬身何日丧"
reading: "侬"在江南方言里指"你"也指"我"，黛玉用一个含混的代词把葬花者和被葬者对换——本来是"我葬你（花）"，瞬间变成"以后谁葬我"。这一对调不是修辞游戏，是黛玉哲学的浓缩：她把自己提前放进了"将被葬"的位置，因此她不是在为花哭，是在为自己未来的孤独哭。这种"提前为自己致哀"的姿态，是黛玉性格最根本的特征——她从不相信现在，因为她已经活在结尾。
```

```
phrase: "侬今葬花人笑痴"
reading: "人笑痴"三字看似自嘲，实则是对整个贾府"乐极"氛围的反讽——别人在笑，她在哭，但她知道笑的人才是真的痴（看不见结局）。这一句把黛玉和宝钗等"豁达派"的根本分歧立住了：不是黛玉爱哭，是只有她在凝视那个所有人都在回避的事实——花会落，人会亡，乐会终。
```

```
phrase: "花落人亡两不知"
reading: "两不知"三字最沉。不是"花知人不知"或"人知花不知"，而是花和人**都不知道**对方的命运——这是宇宙级的孤独。黛玉的悲剧不是她比别人更敏感，而是她意识到敏感也无用——花不知她哭，她不知花痛，悲悯本身是无效的。这种近乎佛家"诸行无常"的认识，把这首诗从少女伤春拔高到了存在论层面。
```

### echoes（≥3 处）

1. **第二十三回 西厢记妙词**——黛玉初闻"良辰美景奈何天"流泪，是本场的预演。两场都用"听见戏文/诗"作为伤春的引子。
2. **第七十六回 凹晶馆联诗**——黛玉湘云联出"冷月葬花魂"，把"葬花"升级为"葬魂"，本场的母题在那里得到彻底完成。
3. **第九十八回 苦绛珠魂归离恨天**——黛玉之死。本场的"未卜侬身何日丧"在那里得到答案——焚稿断痴情，无人为她葬花，就像她预言的那样。

> 总字数估算 ≥1100 字。

## §G · 工作示例 2（DOWNGRADE）：学会闲聊（工具书）

> 工具书的"场景"是作者书里给的标志性对话剧本。此例展示降级版 dissection。

**scene_title**：电梯里的 30 秒——书中"如何在通勤里破冰"剧本

**scene_locus**：第三章 · "短时间高密度对话" · 作者给的剧本范例。

**original_text_excerpt**（≥200 字）：从书中第三章作者给出的"电梯偶遇陌生同事"完整对话剧本摘录（≥200 字）。

### 简化版三层拆解（语言+潜文本+结构功能为主）

**language**：作者使用的"开放式问句 + 具体细节"结构——"你今天那双鞋好特别，是哪里买的？" 而不是 "你好"。具体性是破冰的核心，泛泛的 small talk 反而尴尬。

**subtext**：作者在剧本中刻意安排的**两次失败选项**（"你好" / "今天天气真好"）和**一次成功选项**——失败选项是作者帮读者标定 antipattern，让"应该说什么"变成"不应该说什么"的反向定位。

**structural_function**：本剧本是全书"3 层破冰术"模型的入口示范，后面所有进阶剧本都是它的变形。它在全书结构里承担"模型最简形态的演示"。

### key_close_reads（≥3 条）

针对剧本中"鞋的颜色很特别"、"我注意到你"、"我不打扰你了"三个短语做细读，每条 ≥80 字。

### echoes

与书后面"30 分钟深度对话剧本"、"5 分钟会议破冰剧本"形成 3 层呼应。

> 总字数估算 ≥800 字（降级版下限）。

## §H · 反例（不该入选 scene_dissections）

### H.1 · 纯抽象论证书（如《人类简史》整体）

赫拉利的论证大段是"想象共同体的产生 + 农业革命 + 资本主义起源"——这些是**论证段**，不是场景。整本书没有具体场景值得 5 层拆解。**正确做法**：scene_dissections 留空（per §2.6 OPTIONAL for 论证书 / DOWNGRADE 仅当书里真的有情境化论证片段）；或者降级到 §C "情境化论证片段" ≥2 条。

### H.2 · 纯模型工具书（如《GTD》）

整本书是"收集 → 处理 → 组织 → 回顾 → 执行"的流程模型，没有叙事场景，也没有标志性对话剧本（除了几个泛泛的例子）。**正确做法**：scene_dissections 留空；把厚度转移到"实操剧本 ≥3 个"和"主题级覆盖 ≥8"上。

### H.3 · 纯数学/逻辑学书

无法可拆。留空。

## §I · 自检清单

写完一条 scene_dissection 后逐条核对：
- [ ] 三条入选信号都满足？（母题相关 + 结构枢纽 + 感官密度）
- [ ] 5 层全部展开（blocking / language / sensorium / subtext / structural_function）？
- [ ] 每层 ≥150 字？
- [ ] original_text_excerpt ≥300 字（兼叙事美学书 / 巨著 ≥150 字最低）？
- [ ] key_close_reads ≥3 条，每条 reading ≥80 字？
- [ ] echoes ≥3 处？
- [ ] 总字数 ≥1000 字（降级版 ≥800）？
- [ ] 渲染为深读独占模块？
