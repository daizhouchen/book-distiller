# Thought Coordinates Protocol · 思想坐标四维填充指南

本文档是 `deepening-protocol.md §2.5` 的实施细则。`thought_coordinates` 是 v1 已存在但常常空白的字段，v2 强制四维各 ≥ 3 条（§1.9-1.12），且每条必须按 §2.5 给出的结构化 JSON 填写。本指南给出每一维的判别启发式、GOOD/BAD 对照样例、以及 JSON 结构填写示范。

---

## 总纲 · 四维定义速查（呼应 §2.5）

| 维度 | 时间/立场关系 | 一句话定义 | 易混项 |
|------|-------------|----------|-------|
| 同题延伸 | 横向（同时代或不同时代均可） | 处理**同样母题**、立场不一定对立的其它作品 | 容易和"承继"混；判别：是否在同一时间链条上有传承关系 |
| 对立视角 | 横向对抗 | 处理同样母题但**立场相反**或方法相反的作品 | 容易写成"另一本不同主题的书"；判别：母题必须可比较 |
| 承继关系 | 纵向时间轴 | 本书继承自谁（向前），谁继承自本书（向后） | 容易写成"作者的偶像列表"；判别：必须有可考证的影响链 |
| 现代回响 | 当代 → 本书 | 当代理论/事件/作品对本书母题的呼应或反驳 | 容易写成"我个人感想"；判别：必须有可指认的现代载体 |

每一维 ≥ 3 条是硬下限。低于 3 条 = quality_check 红灯，回流到步骤 3（信源采集）和步骤 6（骨架组装）。

---

## §1 · 同题延伸（≥ 3 条 · §1.9）

### 1.1 定义

处理**同样母题**的其它作品。立场可同可异，关键是母题可比较。如果你的本书母题是"欲望的自噬循环"（金瓶梅），那么任何写"欲望→毁灭"递归结构的书都可入选。

### 1.2 识别启发式

- **三步法**：先把本书母题压缩成一句话（≤ 30 字）→ 列出 5-10 个母题关键词 → 检索"同关键词 + 经典作品"
- **不要选**：只是题材相同但母题不同的作品。例如"都写了爱情"不算同题——母题层级要更深
- **优先选**：跨文化、跨时代的同题作品（更显示母题的普遍性）
- **检索工具**：Google Scholar 检索"X 母题 + 比较文学"；维基百科"主题列表"；Goodreads 的"similar themes"标签

### 1.3 GOOD 例子（红楼梦 · 母题=贵族家族的盛极而衰与情之幻灭）

```json
{
  "referenced_work": "金瓶梅",
  "referenced_author": "兰陵笑笑生",
  "position": "通过西门庆一家的兴衰展示欲望驱动下的盛极必衰，与红楼以情为核不同，金瓶以欲为核",
  "relation_to_book": "脂砚斋批语明言『深得金瓶壸奥』，红楼承袭金瓶的家族日常写法但把『欲』升华为『情』"
}
```

```json
{
  "referenced_work": "源氏物语",
  "referenced_author": "紫式部",
  "position": "贵族男性源氏的多情人生与最终的『物哀』，与宝玉的通灵幻境构成东亚贵族男性叙事双璧",
  "relation_to_book": "同写贵族家族盛衰 + 多情男主，但源氏强调『物之哀』静观，红楼强调『色空』顿悟"
}
```

### 1.4 GOOD 例子（人类简史 · 母题=想象共同体构建世界）

```json
{
  "referenced_work": "想象的共同体",
  "referenced_author": "本尼迪克特·安德森",
  "position": "民族是『想象的政治共同体』，由印刷资本主义和共同语言制造",
  "relation_to_book": "赫拉利的『虚构故事』论直接借用安德森的概念框架，但把范围从民族扩大到所有大规模合作"
}
```

### 1.5 BAD 例子（避免）

```json
// 错误1：母题不可比较
{"referenced_work": "百年孤独", "position": "魔幻现实主义代表作", "relation_to_book": "都是名著"}
// → 母题没对齐，"都是名著"不是关系
```

```json
// 错误2：泛泛而谈
{"referenced_work": "三国演义", "position": "讲了三国故事", "relation_to_book": "中国古典小说"}
// → position 没指出母题层立场
```

## §2 · 对立视角（≥ 3 条 · §1.10）

### 2.1 定义

处理**同样母题但持相反立场**或**反向方法论**的作品。不是简单的"反派书"，而是在同一题域内构成观点对抗的作品。

### 2.2 识别启发式

- **同题前置**：先确定母题对立面。母题"欲望的自噬"→ 对立面 = "欲望的升华/可控"
- **方法对立**：如本书用感性叙事，对立可选用纯理性论证同一主题
- **价值对立**：如本书肯定 X，找否定 X 的代表作
- **检索词**：用"反 + 母题关键词"或"批判 + 作者"在 Google Scholar 检索

### 2.3 GOOD 例子（红楼梦 · 对立母题=以入世奋斗代替出世幻灭）

```json
{
  "referenced_work": "西游记",
  "referenced_author": "吴承恩",
  "position": "通过取经路上的磨难证成『心猿意马可驯，欲念可降伏』的乐观救赎论",
  "relation_to_book": "红楼说『一切归空』，西游说『一切可修』；同写佛理但红楼是悲观幻灭，西游是乐观取经"
}
```

```json
{
  "referenced_work": "封神演义",
  "referenced_author": "许仲琳",
  "position": "贵族（殷商王族）的覆灭是天命使然、新秩序的开端而非情之幻灭",
  "relation_to_book": "同写贵族覆灭，封神是『历史的必然』视角，红楼是『个体的哀感』视角"
}
```

### 2.4 GOOD 例子（学会闲聊 · 母题=用技巧打开陌生人）

```json
{
  "referenced_work": "沉默的力量",
  "referenced_author": "苏珊·凯恩",
  "position": "内向者无需用闲聊技巧伪装外向；深度沟通而非话术才是真正的连接",
  "relation_to_book": "本书教你『如何快速套近乎』，凯恩反对这种表演式社交，主张『让安静成为优势』"
}
```

### 2.5 BAD 例子

```json
// 错误：仅是不同领域，不构成对立
{"referenced_work": "时间简史", "position": "讲宇宙学", "relation_to_book": "和红楼梦没关系所以是对立"}
// → 必须在同一母题域内对立才算
```

## §3 · 承继关系（≥ 3 条 · §1.11）

### 3.1 定义

**纵向时间轴**上本书的上下游：本书继承自谁（向前/上游）+ 谁继承自本书（向后/下游）。必须是可考证的影响链，不是泛泛"读过 X"。

### 3.2 识别启发式

- **向前**：作者亲口承认的影响 + 学界考证的源流 + 作品中明显的化用
- **向后**：后世作品中可指认的化用 + 学者归纳的"X 派"传承
- **要求**：3 条至少 1 条向前 + 1 条向后；不能全是上游或全是下游
- **检索词**："X 影响" + "X 之于 Y" + "X 派"；学术著作《XXX 流派研究》最有用

### 3.3 GOOD 例子（红楼梦 · 上游+下游）

```json
{
  "referenced_work": "离骚",
  "referenced_author": "屈原",
  "position": "以美人香草寄寓家国之痛、以贵族个体的高洁映照浊世",
  "relation_to_book": "向前承继：曹雪芹自陈『悲愤而作』，红楼的『以情写痛』直接承袭《离骚》的香草美人传统",
  "direction": "backward"
}
```

```json
{
  "referenced_work": "金锁记 / 倾城之恋",
  "referenced_author": "张爱玲",
  "position": "民国旧家族女性的幽闭与凋零，文字密度与心理切片直承红楼",
  "relation_to_book": "向后承继：张爱玲多次自述『红楼梦是我的一切』，金锁记的曹七巧可视为王熙凤的现代变体",
  "direction": "forward"
}
```

### 3.4 GOOD 例子（人类简史 · 上游）

```json
{
  "referenced_work": "枪炮、病菌与钢铁",
  "referenced_author": "贾雷德·戴蒙德",
  "position": "用地理与生态因素解释文明分异，开创大历史写作范式",
  "relation_to_book": "赫拉利继承戴蒙德的大跨度因果链方法，但把生态决定论替换为认知革命/虚构故事",
  "direction": "backward"
}
```

### 3.5 BAD 例子

```json
// 错误：作者有可能读过但无证据链
{"referenced_work": "山海经", "position": "古代神话集", "relation_to_book": "曹雪芹应该读过"}
// → "应该读过"不是承继；必须有作者自陈或文本化用证据
```

## §4 · 现代回响（≥ 3 条 · §1.12）

### 4.1 定义

**当代**（近 30 年内）的理论、事件、作品、社会现象对本书母题的呼应或反驳。必须有可指认的现代载体——人、事、作品、概念，不能是"我感觉"。

### 4.2 识别启发式

- **三种载体**：当代学术理论（如行为经济学、复杂系统）/ 当代事件（具体年份+具体事件）/ 当代作品（电影、剧、小说、综艺）
- **三种关系**：印证（现代经验支持本书母题）/ 翻新（现代版本的同一母题）/ 反驳（现代反例打脸本书）
- **检索词**：本书母题关键词 + 当下年份；豆瓣/B 站"X 现代版本"；Twitter/微博热搜
- **避免**：把"我读后感"当回响——回响必须公共可验证

### 4.3 GOOD 例子（红楼梦 · 三类载体齐全）

```json
{
  "echo_type": "当代作品",
  "referenced_work": "许鞍华《半生缘》/《第一炉香》",
  "year": "1997 / 2021",
  "echo_content": "把张爱玲式的红楼余韵搬上银幕，复刻了贵族凋零的视觉肌理",
  "relation_to_book": "印证：红楼的家族凋零母题在港派文艺片中持续被翻新"
}
```

```json
{
  "echo_type": "当代事件/现象",
  "referenced_work": "刘心武揭秘红楼梦（百家讲坛 2005）",
  "year": "2005-2007",
  "echo_content": "索隐派在大众文化中的复活，引发了学界与民间对红楼解读权的争论",
  "relation_to_book": "翻新：红楼的索隐传统在新世纪以电视讲坛形式重生"
}
```

```json
{
  "echo_type": "当代理论",
  "referenced_work": "豪门剧《大宅门》《白鹿原》/ 现实题材『豪门破产』新闻",
  "year": "2001 / 2017 / 持续",
  "echo_content": "中国家族叙事在影视和现实中持续上演盛极而衰的循环",
  "relation_to_book": "印证：红楼的家族盛衰母题具有跨时代普适性"
}
```

### 4.4 GOOD 例子（学会闲聊）

```json
{
  "echo_type": "当代现象",
  "referenced_work": "短视频时代的『15 秒首因效应』",
  "year": "2018-至今",
  "echo_content": "TikTok/抖音的开头 3 秒法则把本书的『首因效应』压缩到极致",
  "relation_to_book": "翻新：闲聊的首因技巧在短视频时代变成了算法层面的硬约束"
}
```

### 4.5 BAD 例子

```json
// 错误：没有具体载体
{"echo_type": "感想", "referenced_work": "我们这个时代", "echo_content": "现在人也都很欲望"}
// → "现在人"不是载体；必须落到具体事件、作品、理论
```

## §5 · JSON 总结构（呼应 §2.5）

完整 thought_coordinates 字段示意：

```json
"thought_coordinates": {
  "同题延伸": [
    {"referenced_work": "...", "referenced_author": "...", "position": "...", "relation_to_book": "..."},
    {...}, {...}
  ],
  "对立视角": [
    {"referenced_work": "...", "referenced_author": "...", "position": "...", "relation_to_book": "..."},
    {...}, {...}
  ],
  "承继关系": [
    {"referenced_work": "...", "referenced_author": "...", "position": "...", "relation_to_book": "...", "direction": "backward | forward"},
    {...}, {...}
  ],
  "现代回响": [
    {"echo_type": "理论 | 事件 | 作品", "referenced_work": "...", "year": "...", "echo_content": "...", "relation_to_book": "..."},
    {...}, {...}
  ]
}
```

每维 ≥ 3 条；承继维度建议 backward + forward 都覆盖；现代回响建议三种载体（理论/事件/作品）至少出现两种。

## §6 · 失败回流

| 现象 | 回流到 | 原因 |
|------|--------|------|
| 某维 < 3 条 | 步骤 3（信源采集）+ 步骤 6（骨架组装） | 没主动检索外延 |
| 某条 position 空泛 | 步骤 3 | 没读到二手解读 |
| 同题/对立混淆 | 步骤 6 | 母题没压缩到 30 字以内导致判别失准 |
| 承继无证据链 | 步骤 3 | 没查作者自述/学界考证 |
| 现代回响无载体 | 步骤 3 | 用了感想代替事实 |

加深不是堆字。思想坐标的填充让本书"嵌入"思想史的网络中——不是孤立地讲一本书，而是让读者看见这本书的上下游、对手、和今天的回声。
