# Schools & Versions · 学派论争与版本差异填充指南

本文档是 `deepening-protocol.md §2.1` 与 `§2.2` 的合并实施细则，对应 §4.1 / §4.2 的适用性判定。两个字段共享同一适用性判断逻辑（古典/经典必填，工具书/单一现代书不适用），故合并讲解。

---

## §1 · 适用性决策树（呼应 §4.1 / §4.2）

```
                  这本书是否写于 1900 年前？
                          /         \
                       是              否
                       /                 \
       schools 必填 ✅              是否为思想史经典（康德/马克思/尼采/海德格尔）？
       versions 必填（如有版本）✅              /          \
                                            是              否
                                          /                  \
                            schools 必填 ✅                是否有重要译本之争 / 修订版差异？
                            versions 必填（如有）✅                  /         \
                                                                 是            否
                                                                /                \
                                                schools 视情况；versions 必填        schools 不适用 ❌
                                                                                  versions 不适用 ❌
                                                                                  （留空，不扣分）
```

### 1.1 经典必填清单（schools_of_interpretation）

按 §4.1 强制清单：

- **中国古典**：红楼梦、金瓶梅、水浒、三国、西游、金刚经、道德经、论语、庄子、史记、诗经、左传、孟子、楚辞
- **西方经典**：圣经、伊利亚特、奥德赛、神曲、莎士比亚作品（哈姆雷特/李尔王/麦克白等）、堂吉诃德、源氏物语、追忆似水年华、浮士德
- **思想史**：康德三大批判（《纯粹理性批判》《实践理性批判》《判断力批判》）、马克思《资本论》《1844 年手稿》、尼采全集（查拉图斯特拉、悲剧的诞生、道德的谱系）、海德格尔《存在与时间》、黑格尔《精神现象学》
- **任何写于 1900 年前且仍在被解读争论的书**

### 1.2 经典必填清单（version_variants）

按 §4.2 强制清单：

- **中文古籍版本/钞本**：红楼梦（甲戌/庚辰/己卯本 vs 程甲/程乙本）、金瓶梅（词话本 vs 崇祯本/张评本）、史记（百衲本 vs 中华书局点校本）、道德经（王弼本 vs 帛书本 vs 楚简本）、莎士比亚（First Folio vs Quarto）
- **重要译本之争**：佛经汉译（鸠摩罗什 vs 玄奘）、圣经（KJV vs NIV vs 和合本 vs 思高本）、追忆似水年华（李恒基 vs 周克希译本）、源氏物语（丰子恺 vs 林文月）
- **同一作者修订版差异**：尼采《查拉图斯特拉如是说》前后版本、卡夫卡遗稿（布罗德编订 vs 校勘新版）

### 1.3 不适用清单（两字段都留空）

- **工具书**：非暴力沟通、原子习惯、清单革命、学会闲聊、深度工作
- **单一作者立场鲜明的论证书**：乌合之众（时代分歧≠学派之争，可降级为"评价分歧"放在 misreadings）
- **现代单一版本书**：人类简史（除非中文版补遗算 version 可选）、追风筝的人、百年孤独（中译版本差异不算重要分歧）

## §2 · schools_of_interpretation 填充细则（§2.1）

### 2.1 数量与质量要求

- **数量**：适用书 ≥ 3 派（按 §1.1）。三派要互不重叠、视角真正对立或互补
- **位置**：渲染为独立模块，深读独占
- **JSON 字段**：每派必须有 `school` / `core_position` / `key_figures` / `evidence_anchors` / `our_judgment`

### 2.2 三派识别启发式

- **方法论维度**：考据派（重证据） vs 文本批评派（重内文） vs 索隐派（重隐喻） vs 思想史派（重时代）
- **代表人物**：找到每派 ≥ 2 位代表人物，至少 1 位是公认权威
- **证据锚点**：每派 ≥ 1 条具体文献/章节支持，不能空挂"某些学者认为"
- **本书判断**：必须在 our_judgment 给出"采纳/部分采纳/存疑/反驳"——不能全部"采纳"

### 2.3 完整 JSON 例子（红楼梦 · 4 派对照）

    "evidence_anchors": [

    "our_judgment": "部分采纳：脂批确为重要内证，但脂砚斋身份未定，部分批语带个人立场，不能视作绝对权威"
  },
  {
    "school": "索隐派",
    "core_position": "红楼梦影射明清易代政治史 / 顺治董鄂妃恋 / 纳兰家事",

  },
  {
    "school": "考据派",
    "core_position": "红楼梦是曹雪芹自传，考证曹家史实是解读基础",

    "evidence_anchors": [

    "our_judgment": "采纳：考据为解读提供基础地基；但考据本身不能替代文本分析"

### 2.4 BAD 例子（避免）

```json
// 错误1：派别空泛
{"school": "传统派", "core_position": "传统解读", "key_figures": ["古人"], "our_judgment": "采纳"}
// → 没说清"传统派"是什么；key_figures 必须实名
```

```json
// 错误2：全部采纳
// 4 派 our_judgment 全是"采纳"——失去了立场
// → 必须有差异化判断
```

## §3 · version_variants 填充细则（§2.2）

### 3.1 数量与质量要求

- **数量**：适用书 ≥ 5 处对照（按 §1.2）
- **位置**：渲染为独立模块，深读独占
- **JSON 字段**：每处对照必须有 `version_a` / `version_b` / `diff_locus` / `diff_content` / `interpretive_significance`

### 3.2 版本差异识别启发式

**中文古籍三类**：
- **钞本系**：曹雪芹原稿系统（甲戌/己卯/庚辰/戚序/蒙府/列藏/舒序/梦稿等）
- **刻本系**：程伟元/高鹗整理本（程甲、程乙）
- **比对工具**：周汝昌《红楼梦校字记》、冯其庸《红楼梦汇校本》

**翻译版本三类**：
- **同一原文不同译者**：如鸠摩罗什 vs 玄奘《心经》
- **同一译者不同版次**：如思高本/和合本修订版
- **简译 vs 全译**：如《追忆似水年华》七卷全译 vs 节选本

**作者修订版**：
- **早期稿 vs 终稿**：尼采《查拉》第四部存疑
- **作者生前/身后**：卡夫卡布罗德编订 vs 后世校勘

### 3.3 完整 JSON 例子（红楼梦 · 5 处差异 · 庚辰本 vs 程乙本）

### 3.4 跨语言版本例子（追忆似水年华 · 节选）

```json

  "version_a": "李恒基/徐继曾等多人合译本（译林 1989-1991）",
  "version_b": "周克希独译本（人文 2004-2012 · 未完）",
  "diff_locus": "第一卷《在斯万家那边》开篇『长久以来，我都是早早就睡下了』",

  "interpretive_significance": "周译更接近法语原文 longtemps 的时间绵延感；李译为多人合译，风格不一"
}
```

### 3.5 BAD 例子

```json
// 错误1：差异不重要
{"version_a": "甲", "version_b": "乙", "diff_locus": "某页", "diff_content": "改了一个标点", "interpretive_significance": "无"}
// → 必须有解读意义
```

## §4 · 工具书的负例（学会闲聊 · 两字段都不适用）

按 §4.1 / §4.2 不适用条款：

- 学会闲聊为日本现代工具书（2010 年后），单一作者立场鲜明，单一版本，无学派论争
- `schools_of_interpretation` 留空 `[]`
- `version_variants` 留空 `[]`
- 这种留空**不扣分**，反而是正确的判断
- 如果作者有"评价分歧"（如批评者认为本书技巧偏功利），可降级放在 `misreadings` 字段，不要硬塞 schools

```json
"schools_of_interpretation": [],
"version_variants": []
```

## §5 · 失败回流

| 现象 | 回流到 | 原因 |
|------|--------|------|
| 经典书 schools < 3 派 | 步骤 3 | 信源采集没主动找学派代表作 |
| 经典书 versions < 5 处 | 步骤 3 | 没做版本对照检索 |
| 派别 our_judgment 全为"采纳" | 步骤 6 | 立场没差异化 |
| key_figures 空或泛指 | 步骤 3 | 没查具体学者 |
| 工具书硬塞 schools | 步骤 6 | 适用性判定错误，应留空 |
| 版本差异无解读意义 | 步骤 6 | 选错差异点，应选影响母题的差异 |

---

## §6 · 与其它字段的协同

- schools 中的 evidence_anchors 应与 `quote_pairs` 的原文锚点呼应
- versions 中的 diff_locus 若涉及关键回目，应在 `chapter_level_notes` 中也提到
- our_judgment 的立场应与本书主线分析（modules）保持一致

加深不是堆字。学派与版本字段让经典书"立体"起来——读者不只看一个解读，而是看见解读传统的张力本身。
