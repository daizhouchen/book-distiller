# 诗词曲赋专题协议（Poetics Dossier Protocol · §2.8）

**v2.1 新增**——本协议规范 `poetics_dossiers` 字段（per `deepening-protocol.md` §2.8 / §4.6）的填写。它把含诗词曲赋的书里的"诗"从装饰提升到独立专题——形式分析 + 化用考据 + 命运预告三件套必须齐全。

> 诗词专题不是"诗作翻译"，也不是"作者很会写诗"的赞叹。它是把一首诗（或一段诗化论证）当作**独立文本对象**来研究——它的形式怎么生效、它化用了什么前文学、它在叙事/论证里承担什么独家功能。

---

## §A · 8 子字段 schema 详解（per §2.8）

```json
{
  "title": "篇名（如：葬花词 / 姽婳词 / 咏螃蟹）",
  "locus": "第 N 回 / 章节定位",
  "speaker_or_voice": "由谁所作 / 叙事声音",
  "full_or_excerpt": "全文 或 关键节选 ≥150 字",
  "form_analysis": "形式分析（体裁、韵律、典故运用）≥150 字",
  "content_analysis": "内容分析（在情节/人物中的功能）≥200 字",
  "intertextual_anchors": [
    {"refers_to": "化用了什么前文学", "significance": "意义"}
  ],
  "fate_foreshadowing": "诗词中的命运预告（如有）≥80 字"
}
```

每条总字数 ≥**600**。

### A.1 · `title`

诗的标题，按原书叫法。无标题的诗（如《红楼梦》第五回的判词、判曲）按通行命名（如"林黛玉判词"、"晚韶华曲"）。

### A.2 · `locus`

精确定位：第几回 / 第几章 / 第几节，必要时附场景（如"第二十七回 · 葬花场"）。

### A.3 · `speaker_or_voice`

谁说的 / 谁写的：
- 角色之作（如黛玉作《葬花词》）—— 写明角色名 + 当时情境（"在葬花的午后"）
- 叙事者声音（如《三国演义》开篇"滚滚长江东逝水"——是叙事者总评，不是某角色）
- 引用前人（如《红楼梦》中对古诗的化用——要分清是角色引用还是作者借力）

`speaker_or_voice` 字段要诚实——古典小说的诗词常有"借角色之口说作者之言"的层次，要点破。

### A.4 · `full_or_excerpt`（≥150 字）

短诗全文录入；长篇节选关键段落。**不要只录两三行**——形式分析需要足够的文本量做支撑（如声律、对偶、章法都要全篇/大段才看得出）。

### A.5 · `form_analysis`（形式分析，≥150 字）

⭐ 这是 dossier 区别于"翻译加感想"的根本层。

要素清单：

**§A.5.1 · 体裁**：
- 诗（古风/律诗/绝句/乐府）
- 词（婉约/豪放/小令/长调，词牌名）
- 曲（散曲/套曲，曲牌名）
- 赋（骈赋/律赋/古赋/文赋）
- 偈（佛教偈语）
- 诗化散文段（思想散文里的密度高段）

每种体裁有自己的"游戏规则"——分析必须在规则内进行。律诗讲对仗讲平仄，词讲词牌讲句读，曲讲衬字讲套数，乱套等于没读。

**§A.5.2 · 韵律 / 声调 / 节奏**：
- 押韵格式（一韵到底 / 换韵 / 入声韵的特殊情绪）
- 平仄安排（律诗的工对程度）
- 节奏（短句紧、长句缓）

**§A.5.3 · 典故运用**：
- 这首诗用了哪些典故？
- 是明用还是暗用？
- 化用对象的原义和此处用法的差异（最能见功夫的层）

**§A.5.4 · 修辞结构**：
- 起承转合
- 比兴
- 对偶 / 排比 / 倒装 / 设问

> form_analysis 不是文学课讲义——是**为什么这种形式选择服务于这一刻的内容**。形式分析的金标准：能否论证"如果换一种体裁/声律/句式，这首诗会失去什么"。

### A.6 · `content_analysis`（内容分析，≥200 字）

形式之外，诗在情节 / 人物 / 论证中承担什么？

要素清单：

- **情节功能**：推动情节？暂停情节做内省？预告下文？
- **人物功能**：定调人物（如初次出场的诗确立形象）？暴露人物的隐秘想法？把人物从行动者变成沉思者？
- **结构功能**：在全书结构里和别处呼应？
- **抒情/议论功能**：作者借诗议论一个无法用散文说清的事（如生死、无常、爱欲）

> form_analysis 和 content_analysis 的边界：form 关注"怎么说的"，content 关注"说了什么 / 这一段在做什么工作"。两者**都不能省**——只看 form 是形式主义空壳，只看 content 是把诗当散文。

### A.7 · `intertextual_anchors`（化用前文学，≥2 条）

```json
[
  {"refers_to": "化用了什么前文学", "significance": "为什么这个化用关键"}
]
```

要素：
- **明确锁定前文本**——化用了《楚辞》某句？《庄子》某典？《诗经》某意象？还是同代人的诗？
- **化用方式**——直引 / 倒用 / 反用 / 暗用
- **化用的功能**——借力 / 反讽 / 致敬 / 解构

化用的考据是 dossier 含金量的硬指标。"她写了一首诗很美"是描述；"她在第三句化用了《九歌·湘君》'帝子降兮北渚'，把屈原对神女的呼唤翻成对自己的预言"——这才是 dossier。

### A.8 · `fate_foreshadowing`（命运预告，≥80 字，适用时）

⭐ 古典小说里诗词的特殊功能。

中国古典小说（红楼/金瓶/西游/水浒）有一个独特传统：**诗词承担命运预告**。同一句话用散文说出来轻飘，用诗写下来就成了命运的判词。

要素：
- 这首诗是否预告了某人 / 某事的结局？
- 预告以什么方式呈现（明说 / 暗藏 / 谶语形式）？
- 预告的兑现在哪里？

并非每首诗都有 fate_foreshadowing 功能（如纯抒情诗、纯论辩诗）——可空。但古典小说的"判词 / 判曲 / 重要场合的诗"几乎都有此功能。

## §B · form_analysis vs content_analysis 的边界

实战中最容易混淆。规则：

| 维度 | form_analysis | content_analysis |
|------|------|------|
| 关注点 | 形式怎么生效 | 形式服务于什么 |
| 工具 | 体裁学 / 声律学 / 修辞学 | 情节学 / 人物学 / 母题分析 |
| 典型句 | "用了入声韵，所以情绪是顿挫的" | "这首诗在情节上是黛玉的命运预告" |

> 写完 form_analysis 自检：是否完全没碰人物 / 情节？
> 写完 content_analysis 自检：是否完全没分析诗的形式技巧？
> 二者必须各自独立成段（不能混着写）——这是 v2.1 §2.8 schema 的**显式分割**要求。

## §C · 典故运用 / 化用前文学的考据

化用考据是诗词专题的"指纹检验"层。要点：

### C.1 · 三层化用类型

- **明用**：直接引用前人原句，如"红尘有恨"化用李商隐"此情可待成追忆"——读者一望即知。
- **暗用**：化用意境而不引原句，如《葬花吟》"质本洁来还洁去"暗合屈原"宁赴常流而葬乎江鱼腹中耳"——读者要识别。
- **反用**：化用原义但翻转，如"花谢花飞花满天"借唐人春日意象但翻成悼亡——形似而义反。

### C.2 · 化用考据的写法

不是"她引用了 XX"——而是：
1. 锁定原文出处（具体到篇名 / 句号）
2. 解释原文在原典里的含义
3. 解释此处用法和原义的关系
4. 解释为什么作者选这个典而不是别的（同义典的可替代性比较）

### C.3 · 化用考据的反例

错误写法：
> "黛玉的诗化用了很多前人。"

正确写法：
> "《葬花吟》'尔今死去侬收葬，未卜侬身何日丧'两句，化用宋人方岳《春思》'东风不为吹愁去，春日偏能惹恨长'的句式——以'东风'这种自然力量的不可逆做参照，黛玉把'侬'放在自然力量的位置上，反差出'人能葬花，谁葬人'的虚空。同时句式上又呼应屈原《九章·涉江》'死而又何畏？哀吾生之悠悠'——把屈原的政治流亡转译为闺中少女的存在论孤独。"

## §D · 命运预告功能在古典小说里的特殊性

中国古典叙事文学有一个独特的**诗词预告体系**——不只是"诗里隐含意味"，是诗作为**命运的物质形式**。

### D.1 · 红楼的判词体系（第五回）

第五回宝玉游太虚幻境，看到金陵十二钗判词 + 判曲——这十二段诗词把全书所有女性角色的命运提前固定。**关键技巧**：判词使用谶语（双关、藏字、典故隐写），读者第一遍读不懂，读到结局回看才明白。

### D.2 · 三国的开篇与结尾词

"滚滚长江东逝水"作为开篇——把整本书框入"是非成败转头空"的预设结尾里。这是叙事者声音的强制框定。

### D.3 · 水浒的"宋江浔阳楼题反诗"

诗的内容（"敢笑黄巢不丈夫"）成了宋江后来"被栽赃造反"的物质证据——诗在这里是事件的因果起点，不只是抒情。

### D.4 · 命运预告的写法在 dossier 里

`fate_foreshadowing` 字段不能只写"这首诗预告了 XX 的命运"——要写：
- 预告的具体方式（哪一句对应哪一事）
- 兑现的具体场景（在第几回兑现）
- 预告的"刚好不被听见"——古典叙事最妙的是预告写得很明白但角色 / 一般读者都不懂，等结局来了才回头明白。这种"事后才生效"的预告，是古典叙事比现代叙事多出的一层。

## §F · 工作示例 2（思想散文诗化片段）：庄子《逍遥游》大鹏南徙片段

```json
{
  "title": "大鹏南徙（《逍遥游》开篇至'此小大之辨也'）",
  "locus": "《庄子·内篇·逍遥游》第一段",
  "speaker_or_voice": "庄子叙事声音，但通过'齐谐者，志怪者也'引入第二层叙事者，再用'蜩与学鸠笑之曰'引入第三层。这种**多层声音嵌套**使论辩不像论辩，而像神话——这是庄子论证最独特的形式选择。",
```

## §G · 不适用书：现代纯叙事小说 / 工具书

### G.1 · 现代纯叙事小说（如《活着》《许三观卖血记》）

```json
"poetics_dossiers": []
```

现代白话小说一般无诗词曲赋。**不强填**——按 §4.6 OPTIONAL 留空，在卷首 applicability_map 注明 not_applicable + 一句话理由（"全书无诗词曲赋"）。

### G.2 · 工具书（如《学会闲聊》《非暴力沟通》）

```json
"poetics_dossiers": []
```

工具书无诗词内容，留空。卷首 applicability_map 注明 not_applicable。

### G.3 · 边界情况：现代小说里的零星诗化段落

如《百年孤独》开篇"多年以后……"这一句虽具有诗化的回旋感，但单点不构成 dossier 对象。判定标准：**是否能写出 ≥150 字 form_analysis + ≥200 字 content_analysis**——写不出，说明这段不是 dossier 对象，归入精读模块的普通段落即可。

## §H · 自检清单

写完一条 poetics_dossier 后逐条核对：
- [ ] 8 子字段全部填写？
- [ ] full_or_excerpt ≥150 字（不是只录两三行）？
- [ ] form_analysis ≥150 字，含**体裁/韵律/典故/修辞**四要素？
- [ ] content_analysis ≥200 字，含**情节/人物/结构/抒情**功能？
- [ ] form 和 content 各自独立成段（不混着写）？
- [ ] intertextual_anchors ≥2 条，每条**锁定具体出处 + 化用方式 + 化用功能**？
- [ ] fate_foreshadowing（适用时）≥80 字，含**预告方式 + 兑现场景**？

任何一条失败 → quality_check 红，回流重写本条。

## §J · 与 §2.6 场景细读 / §2.7 人物小传的协同

三个新字段在巨著里常常**互相引用**：

- 《葬花词》是诗词专题的一条，也是黛玉 dossier 的 key_scene 之一，也是黛玉葬花场景细读的核心文本——三个模块互相指向同一个文本中心。
- 在 distill.json 里，这种交叉引用要用 cross_link 字段标注：

```json
"poetics_dossiers": [
  {
    "title": "葬花词",
    "...": "...",
    "cross_links": {
      "scene_dissection": "葬花场（第二十七回）",
      "character_dossier": "林黛玉"
    }
  }
]
```

> 三个字段的协同使巨著的产物形成"立体网络"——同一个文本中心从场景视角、人物视角、诗学视角分别打开。这是 v2.1 在巨著上的关键密度跃迁来源。
