# 示例 · 红楼梦 骨架（v2 加深版示范）

> **v2 加深版示范** —— 本文件是 book-distiller v2 协议（`references/deepening-protocol.md`）下的旗舰示例。所有 v1 字段保留，5 个新字段（学派论争 / 版本变异 / 作者立场解构 / 章节级覆盖 / 强化思想坐标）按 §4 适用性规则**全部触发**——红楼梦是《§5.1 巨著 · 全适用》的标本。其它示例（金瓶梅 / 遥远的救世主 / 非暴力沟通）按各自基因与体量，部分触发或降级处理。

基因：**人物(主) + 叙事 + 美学 + 体验**（多基因共生，per `genes.md`）

母题：**繁华如尘，情根难断——以家族崩塌为镜照见生命无常**

记忆抓手：**石头入凡 · 还泪一场**

骨架引用：`skeletons/character-heavy.md` 主 + `skeletons/aesthetic-heavy.md` 兼（per §1.1，红楼是 character + aesthetic 双骨架共生案例）

适用性判定（per §4）：
- §2.1 学派论争 → ✅ 强制（红楼是中国古典学派论争最激烈的文本，无之一）
- §2.2 版本变异 → ✅ 强制（脂本系 vs 程高本系 + 脂本内部多钞本差异）
- §2.3 作者立场解构 → ✅ 强制（所有书强制）
- §2.4 章节级覆盖 → ✅ 强制（120 回，>100 万字，远超 30 万字门槛）
- §2.5 强化思想坐标 → ✅ 四维各 ≥3

# 误读陷阱（per §1.5 ≥5）
# ========================================
misreadings:
  - common_misread: 宝黛是纯爱小说
    why_misread: 言情小说化的传播 / 影视改编对爱情线的强化
    actual: 宝黛之爱是"还泪"的因果，更是"情根能否安放"的哲学问题；曹雪芹的笔重不在恋爱本身，而在"情如何应对无常"
  - common_misread: 红楼梦是政治影射小说（索隐派完全主导）
    why_misread: 蔡元培《石头记索隐》与当代刘心武"秦学"的影响
    actual: 红楼有政治背景潜流，但不是"一对一影射"；胡适考据已基本证伪索隐派的逐字对应
  - common_misread: 高鹗续书全是败笔，应弃之不读
    why_misread: 张爱玲"红楼未完是此生最大遗憾"的强力定调 / 红学界部分学者对高鹗的不满
    actual: 高鹗续书有缺陷（光明尾巴等），但完成了悲剧框架的主体（黛死宝出），且林语堂、白先勇等都有为高鹗辩护的合理论述
  - common_misread: 贾母只是慈祥老祖母，是封建家长的温和象征
    why_misread: 87 版电视剧的塑造 + 通俗读物简化
    actual: 贾母是"权力的微笑面具"——她对鸳鸯（46 回）、晴雯（74 回）、黛玉的处置都体现着深层的家族权力逻辑，远比"慈祥"复杂
  - common_misread: 妙玉是边缘人物，可有可无
    why_invisible: 妙玉的篇幅不大，第 41 回品茶后多线索断裂
    actual: 妙玉是金陵十二钗正册之一，作者把她列为正册第 6 位（在凤姐之上），其重要性远高于影视改编中的处理；妙玉的"槛外人"位置是宝玉日后出家的精神先驱
  - common_misread: 王熙凤是反派
    why_misread: 戏剧化处理 / 因果报应叙事的简化
    actual: 凤姐有恶（毒设相思局、害死尤二姐），但也有能、有情（对刘姥姥的容情、对秦可卿的真情、对巧姐的母爱）；她是"机关算尽"的悲剧人物，不是单纯反派
